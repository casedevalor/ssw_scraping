<h3># 📄 Rotina 704</h3>

Automação para extração, download e envio do relatório da rotina **704** do sistema SSW para o SharePoint.

---

## 📌 Objetivo

Executar a consulta da rotina 704 no SSW, preenchendo os filtros com os parâmetros corretos (datas, tipo, etc), aguardando a geração do relatório e salvando-o em formato `.csv`, enviando-o para o SharePoint automaticamente.

---

## ⚙️ Funcionamento

Executa para o período definido pela função `Dates().calculate_start_to_current_day()`, processando do início até a data atual.

### 🕒 Agendamento
- A rotina pode ser programada para rodar em horário específico (geralmente via `cron`).
- Utiliza a função `Dates().calculate_start_to_current_day()` para definir o período do relatório.

### 📥 Entrada
- Login no sistema SSW com dados cadastrados no módulo de credenciais (`functions/credentials/login.py`)
- Filtro pré-configurado com:
  - Campo "tp_rel" preenchido com "E"
  - Campo "ativo" preenchido com "T"
  - Período (data inicial até a data atual)

### 📤 Saída
- Arquivo `.csv` salvo localmente em `downloads/704/`
- Upload do arquivo para o SharePoint na pasta: `/<DOMÍNIO>/704`
- Nome do arquivo: `<DOMÍNIO>-704.csv`

---

## 🗂 Estrutura dos Arquivos

- `bot_704.py`: Código principal da rotina
- `functions/dates/date_treatment.py`: Define o range de datas (inicial até atual)
- `functions/log/log.py`: Registro de logs de execução e erro
- `functions/playwright_functions/login.py`: Login com tratamento de erro
- `functions/playwright_functions/upload_to_sharepoint.py`: Envio de arquivos para o SharePoint
- `functions/garbage_colector/garbage.py`: Limpeza dos arquivos antigos

---

## 📌 Dependências

- `pandas`
- `SharePlum` 
- `asyncio` 
- `playwright`
